# 网站维护状态管理工具

这是一个部署在 Vercel 上的网站维护工具，用于长期保存域名、批量检测网站状态，并通过标签跳过不需要检测的域名。

## 当前功能

- 域名库保存在当前浏览器的 `localStorage`
- 批量添加域名，自动去重
- 标签、备注和最近检测结果长期保留
- 有标签的域名自动跳过“检测全部无标签域名”
- 预设标签：`已下线`、`未建站`、`暂停维护`、`其他`
- 支持批量打标签、清除标签、删除
- 支持检测全部无标签域名或临时检测选中域名
- 保存最近状态、状态码、说明和检测时间
- 搜索与状态筛选
- 导入、导出域名库 CSV
- 导出本次检测结果
- 添加域名、域名库和检测结果区域支持折叠
- 长域名列表和结果列表在卡片内部滚动，表头固定

## 检测项目

- DNS 是否可以解析
- HTTP 状态码和重定向
- 响应时间
- SSL 证书状态和剩余有效期
- 停放页、默认页和品牌内容异常
- 手机端基础可访问性和 viewport
- 部分图片资源可用性

## 文件说明

```text

manager-compact.html    可折叠、内部滚动的紧凑界面
manager.html            原始域名管理页面
api/check.js            原始检测函数
api/check-v2.js         检测入口与品牌误判修正层
api/brand-fix.js        HTML 实体、首字母品牌和单复数兼容

```

## 本地保存说明

数据只保存在当前浏览器中。以下操作可能导致数据无法继续访问：

- 更换电脑或浏览器
- 使用无痕模式
- 清除浏览器的网站数据
- 更换 Vercel 域名

建议定期点击“导出域名库”保存 CSV 备份。

## 部署到 Vercel

1. 将仓库导入 Vercel。
2. 不需要额外构建命令。
3. 部署完成后直接打开 Vercel 提供的地址。
4. 后续推送到 GitHub 会自动重新部署。

## 检测限制

前端按照每批 8 个域名调用检测接口，后端单次最多接受 100 个域名。大量域名需要分批完成，请不要在检测期间关闭页面。
