# 网站维护状态管理工具

用于长期维护一批域名，而不是每次临时粘贴检测。

## 当前功能

- 批量录入域名并永久保存在当前浏览器
- 给域名添加标签和备注
- 任何非空标签都会自动跳过“全部检测”
- 默认标签：已下线、未建站、暂停维护、其他
- 清除标签后自动恢复检测
- 保存最近检测状态、状态码、说明和检测时间
- 支持检测全部无标签域名
- 支持检测选中的域名
- 支持批量打标签、恢复检测和删除
- 支持导出/导入域名库 CSV 备份
- 支持导出本次检测结果

## 数据保存方式

本项目当前使用浏览器 `localStorage` 保存域名库。

这意味着：

- 刷新页面或关闭浏览器后，数据仍然存在
- 数据只保存在当前浏览器和当前设备
- 更换电脑、使用无痕模式或清除网站数据后，数据不会自动同步
- 建议定期点击“导出域名库”保存 CSV 备份

## 检测规则

点击“检测全部无标签域名”时：

- 无标签域名：参与检测
- 已下线：跳过
- 未建站：跳过
- 暂停维护：跳过
- 其他：跳过

“检测选中域名”可以临时检测选中的有标签域名，但会先弹出确认。

## 项目结构

```text
manager.html    新版域名管理页面
index.html      旧版临时批量检测页面（保留作回退）
api/check.js    Vercel Serverless 检测 API
vercel.json     首页与 API 路由配置
```

## 部署

导入 Vercel 后直接部署即可。`vercel.json` 会把首页 `/` 指向 `manager.html`，API 请求仍然使用 `/api/check`。

## 注意

- 单次 API 请求最多接收 100 个域名
- 前端按每批 8 个域名依次检测
- 本地模式没有账号同步和多人协作能力
